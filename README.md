# IBotServe - Система Telegram Userbot

Автоматизована система для управління множинними Telegram userbot-ами з інтеграцією AI (Grok) для генерації природних повідомлень у групових чатах.

## Опис системи

IBotServe - це Python-система, яка дозволяє керувати декількома Telegram акаунтами (userbot-ами) для автоматичної участі у групових дискусіях. Система використовує AI (Grok API) для генерації контекстуально релевантних повідомлень, створюючи ефект природної бесіди.

### Основні можливості

- **Множинні акаунти**: Підтримка необмеженої кількості Telegram акаунтів
- **Control Bot**: Звичайний Telegram бот для зручного керування юзерботами
- **База даних**: SQLite для зберігання інформації про сесії та ролі
- **Проста авторизація**: Додавання нових юзерботів прямо через Telegram
- **AI-генерація повідомлень**: Використання Grok API для створення природних відповідей
- **Контекстна свідомість**: Збереження історії останніх N повідомлень для кращого розуміння контексту
- **Імітація людської поведінки**:
  - Випадкові затримки між повідомленнями
  - Симуляція набору тексту перед відправкою
  - Уникнення послідовних повідомлень від одного акаунту
- **Гнучка конфігурація**: Налаштування через YAML файл
- **Безпека**: Використання файлових сесій Telethon
- **Логування**: Повне логування всіх операцій

## Структура проекту


## Інструкції по запуску

### 1. Клонування та встановлення залежностей

```bash
# Клонуйте репозиторій або розпакуйте архів
cd IBotServe

# Створіть віртуальне середовище (рекомендується)
python -m venv venv

# Активуйте віртуальне середовище
# Windows:
venv\Scripts\activate
# Linux/Mac:
source venv/bin/activate

# Встановіть залежності
pip install -r requirements.txt
```

### 2. Отримання Telegram API credentials

1. Перейдіть на https://my.telegram.org/auth
2. Увійдіть з вашим номером телефону
3. Перейдіть в розділ "API development tools"
4. Створіть додаток і отримайте **API_ID** та **API_HASH**

### 3. Створення Control Bot

1. Знайдіть [@BotFather](https://t.me/BotFather) в Telegram
2. Надішліть команду `/newbot`
3. Введіть ім'я та username для бота
4. Отримайте **токен бота** (BOT_TOKEN)
5. Збережіть цей токен - він потрібен для `.env`

### 4. Отримання вашого Telegram User ID

1. Знайдіть [@userinfobot](https://t.me/userinfobot) в Telegram
2. Надішліть будь-яке повідомлення
3. Отримайте ваш **User ID** (число)
4. Додайте цей ID в `config.yaml` в розділ `admin_user_ids`

### 5. Отримання Grok API ключа

1. Зареєструйтесь на платформі X.AI
2. Отримайте API ключ в особистому кабінеті
3. За замовчуванням використовується endpoint: `https://api.x.ai/v1/chat/completions`

### 6. Налаштування конфігурації

#### Крок 1: Створіть файл .env

```bash
# Скопіюйте шаблон
copy .env.example .env
# або на Linux/Mac:
cp .env.example .env
```

#### Крок 2: Заповніть .env файл

```env
# Telegram API (з my.telegram.org)
API_ID=ваш_api_id
API_HASH=ваш_api_hash

# Control Bot токен (з @BotFather)
CONTROL_BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrsTUVwxyz

# Grok AI
GROK_API_KEY=ваш_grok_api_ключ
GROK_API_URL=https://api.x.ai/v1/chat/completions
```

#### Крок 3: Налаштуйте config.yaml

```yaml
# ID цільової групи (-100XXXXXXXXXX для супергруп)
group_id: -1001234567890

# Control Bot налаштування
control_bot:
  enabled: true
  admin_user_ids:  # Ваш Telegram User ID (з @userinfobot)
    - 123456789

# Промпт для AI
prompt: |
  Ви берете участь у неформальній груповій дискусії про технології та програмування.
  Будьте природним, дружелюбним і відповідайте контекстуально.
  Уникайте надмірної формальності. Відповідайте коротко (1-3 речення).

# Затримки між повідомленнями (секунди)
delays:
  min_seconds: 30
  max_seconds: 120

# Кількість повідомлень для контексту
max_context_messages: 10
```

**Як дізнатись ID групи:**
1. Додайте [@getmygroupid_bot](https://t.me/getmygroupid_bot) у вашу групу
2. Бот надішле ID групи (наприклад: `-1001234567890`)
3. Скопіюйте це число в `config.yaml`

### 7. Додавання юзерботів через Control Bot

Тепер найпростіший спосіб додавати юзерботів - через Control Bot!

#### Крок 1: Запустіть Control Bot

```bash
python main.py --control
```

#### Крок 2: Знайдіть вашого бота в Telegram

Знайдіть бота за username який ви створили через @BotFather

#### Крок 3: Додайте юзербот сесію

1. Надішліть команду `/start` боту
2. Натисніть кнопку **"➕ Додати сесію"** або надішліть `/add`
3. Введіть номер телефону в форматі `+380123456789`
4. Введіть код підтвердження з SMS
5. Якщо є 2FA - введіть пароль
6. Введіть зручне ім'я для сесії (англійськими літерами)
7. Готово! ✅

#### Крок 4: Встановіть адмін-сесію (опціонально)

Одна з сесій має бути адміністратором (для прослуховування групи):

```
/set_admin назва_сесії
```

#### Крок 5: Перегляд всіх сесій

```
/list
```

Показує всі додані сесії з їх статусами.

### 8. Запуск системи діалогів

Після додавання мінімум однієї сесії, запустіть основну систему:

```bash
python main.py
```

Система автоматично:
- Завантажить всі активні сесії з БД
- Підключить юзерботів до Telegram
- Почне генерувати повідомлення у вказаній групі

### 9. Зупинка системи

Натисніть `Ctrl+C` для коректної зупинки.

## Control Bot - Команди

Control Bot має наступні команди:

### Основні команди

- `/start` - Почати роботу з ботом, показати меню
- `/help` - Довідка по командам
- `/add` - Почати процес додавання нової юзербот сесії
- `/list` - Показати всі додані сесії
- `/delete <session_name>` - Видалити сесію
- `/set_admin <session_name>` - Встановити сесію як адмін
- `/cancel` - Скасувати поточну операцію

### Приклади використання

```
# Додати нову сесію
/add
> Введіть номер телефону: +380123456789
> Введіть код: 12345
> Введіть ім'я: my_bot_1

# Переглянути сесії
/list

# Встановити адміна
/set_admin my_bot_1

# Видалити сесію
/delete old_bot
```

### Рекомендації по налаштуванню

1. **Затримки**:
   - Для активних груп: 30-120 секунд
   - Для спокійних груп: 60-300 секунд

2. **Контекст**:
   - Більше повідомлень = краще розуміння, але більше токенів API
   - Рекомендовано: 5-15 повідомлень

3. **Промпт**:
   - Будьте конкретними щодо тону і стилю
   - Вказуйте тематику дискусії
   - Обмежуйте довжину відповідей

## Безпека і обмеження

### Важливо:

- **Використання userbot-ів може порушувати Terms of Service Telegram**
- Не використовуйте для спаму або шкідливих цілей
- Telegram може заблокувати акаунти за підозрілу активність
- Використовуйте розумні затримки між повідомленнями
- Не додавайте акаунти одночасно в групи
- Зберігайте `.env` та сесії в безпеці

### Рекомендації:

1. Використовуйте окремі акаунти для userbot-ів
2. Не використовуйте особисті акаунти
3. Поступово збільшуйте активність нових акаунтів
4. Регулярно робіть резервні копії сесій

### 1. Control Bot Mode (керування)

Запускає звичайний Telegram бот для керування юзерботами:

**Використання:**

## Troubleshooting

### Проблема: "No active sessions found in database"
**Рішення**:
- Запустіть Control Bot: `python main.py --control`
- Додайте мінімум одну сесію через `/add`
- Встановіть одну з сесій як адмін через `/set_admin`

### Проблема: "Missing required environment variables"
**Рішення**:
- Перевірте файл `.env`, всі поля мають бути заповнені
- Для Control Bot потрібен `CONTROL_BOT_TOKEN`
- Перевірте що скопіювали `.env.example` в `.env`

### Проблема: Control Bot не відповідає
**Рішення**:
- Перевірте токен бота в `.env`
- Перевірте що ваш User ID є в `config.yaml` -> `admin_user_ids`
- Перевірте інтернет з'єднання

### Проблема: "У вас немає доступу до цього бота"
**Рішення**:
- Додайте ваш Telegram User ID в `config.yaml`
- Знайдіть свій ID через [@userinfobot](https://t.me/userinfobot)

### Проблема: Помилка при додаванні сесії через Control Bot
**Рішення**:
- Перевірте правильність номера телефону (формат: +380...)
- Перевірте що `API_ID` та `API_HASH` правильні
- Якщо є 2FA, переконайтесь що ввели правильний пароль

### Проблема: "Session is not authorized"
**Рішення**:
- Видаліть стару сесію через `/delete`
- Додайте нову через `/add`

### Проблема: Grok API повертає помилки
**Рішення**:
- Перевірте API ключ
- Перевірте баланс рахунку Grok
- Система автоматично перейде на fallback-повідомлення

### Проблема: Бот не відправляє повідомлення
**Рішення**:
- Переконайтесь що юзербот акаунти є членами групи
- Перевірте права на відправку повідомлень
- Перевірте правильність `group_id` (має бути від'ємним)
- Перевірте що встановлена адмін-сесія через `/set_admin`

## База даних

Система використовує SQLite для зберігання даних. База створюється автоматично при першому запуску.

### Таблиці

**sessions** - інформація про юзерботів:
- `session_name` - ім'я файлу сесії
- `user_id` - Telegram User ID
- `username` - Username акаунту
- `first_name`, `last_name` - Ім'я та прізвище
- `phone` - Номер телефону
- `is_admin` - Чи є адміністратором
- `is_active` - Чи активна сесія

**auth_sessions** - тимчасові дані для авторизації нових сесій

**settings** - загальні налаштування системи

### Резервні копії

Рекомендується регулярно робити backup бази даних:

```bash
# Windows
copy ibotserve.db ibotserve_backup.db

# Linux/Mac
cp ibotserve.db ibotserve_backup.db
```

## Розширення функціоналу

### Додавання медіа

Файл `media_handler.py` містить заглушки для роботи з медіа. Реалізуйте методи:
- `get_random_media()` - вибір випадкового медіа
- `download_media_from_url()` - завантаження медіа
- `validate_media_file()` - валідація медіа файлів

### Власний AI provider

Замініть `ai_client.py` на власну реалізацію для інших AI сервісів:
- OpenAI GPT
- Claude
- Local LLM (llama.cpp, Ollama)

### Міграція існуючих сесій

Якщо у вас вже є `.session` файли в папці `sessions/`:

1. Запустіть Control Bot
2. Для кожного файлу створіть запис через `/add` (використовуючи той же номер)
3. Або створіть міграційний скрипт для автоматичного додавання в БД
